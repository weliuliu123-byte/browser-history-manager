# Captured Benchmark Results (`results/`)

Raw Windows QPC profiler output, structured CSV metrics, and rendered scaling figures generated by compiling and running CLI Option `10` (`Run Performance Benchmark`) on the project C++11 binary.

---

## Tracked Artifacts

| File | Description |
| :--- | :--- |
| `benchmark_report.txt` | Complete captured stdout from Option `10` (`N = 10..10000`, 1,000-iteration averages) |
| `benchmark_metrics.csv` | Structured CSV table extracted from `benchmark_report.txt` |
| `benchmark_latency.png` | 2x2 log-log latency comparison (`BrowserHistory` DLL vs `TwoStackSimulator`) |
| `dll_performance.png` | Dual-axis DLL memory working-set delta (`KB`) vs `O(N)` search/delete latency (`us`) |
